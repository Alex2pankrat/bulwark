## Kenney asset packs — Creative Commons Zero 1.0 (CC0)

Source: <https://kenney.nl> · Licence: <https://creativecommons.org/publicdomain/zero/1.0/>

Used for every sprite and sound effect:

| Pack | Used for |
|---|---|
| **Tower Defense (Top-Down)** | tower sprites, enemy sprites, scenery props |
| **Particle Pack** | impact/explosion/muzzle effect textures |
| **Interface Sounds** | UI clicks, back, confirm, error |
| **UI Audio** | hover feedback |
| **Impact Sounds** | tower build/sell, enemy hits, leaks |
| **Digital Audio** | weapon fire sounds |
| **Music Jingles** | victory / defeat stingers |

CC0 places the work in the public domain: attribution is not required, but the packs are
credited in-game and here because Kenney's work deserves it.

The licence text shipped with each pack is kept next to the audio in
`assets/audio/*_LICENSE.txt`, and the pack licence for the sprites is in
`assets/audio/tower-defense-top-down_LICENSE.txt`.

## Generated content

`assets/audio/music/calm.ogg` and `battle.ogg`, the app icons, and every UI icon in
`src/ui/icons.gd` are generated by scripts in this repository (`tools/make_music.py`,
`tools/` icon script). They are released under CC0 1.0 alongside the asset packs, so the
whole shipped product can be reused freely.
